##  Условие задачи (Вариант 29,номер по списку группы)
29. Записать программу, которая на ввод времени суток выводит
соответствующее пожелание доброго утра, доброго дня, доброго вечера и
спокойной ночи.
## Логика распределения времени (общепринятый вариант):
*  **05:00 – 11:59 — Доброе утро**
*  **12:00 – 17:59 — Добрый день**
*  **18:00 – 22:59 — Добрый вечер**
*  **23:00 – 04:59 — Спокойной ночи**
## 1.Алгоритм и блок-схема
## Алгоритм
1. Начало.
2. Объявление целочисленной переменной hour.
3. Ввод значения hour с клавиатуры.
4. Проверка условия (конструкция switch):
   
   Если hour равно 0, 1, 2, 3, 4 или 23, то вывести «Спокойной ночи!» и перейти к шагу 5.
   
   Если hour равно 5, 6, 7, 8, 9, 10 или 11, то вывести «Доброе утро!» и перейти к шагу 5.
   
   Если hour равно 12, 13, 14, 15, 16 или 17, то вывести «Добрый день!» и перейти к шагу 5.
   
   Если hour равно 18, 19, 20, 21 или 22, то вывести «Добрый вечер!» и перейти к шагу 5.
   
   Если hour не совпало ни с одним из вышеперечисленных значений, то вывести «Ошибка! Введите число от 0 до 23.».
   
5. Конец программы.

## 2. Реализация программы
```c
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    int hour;
    printf("Введите время (часы от 0 до 23): ");
    scanf("%d", &hour);
    switch (hour) {
    case 0: case 1: case 2: case 3: case 4: case 23:
        printf("Спокойной ночи!\n");
        break;
    case 5: case 6: case 7: case 8: case 9: case 10: case 11:
        printf("Доброе утро!\n");
        break;
    case 12: case 13: case 14: case 15: case 16: case 17:
        printf("Добрый день!\n");
        break;
    case 18: case 19: case 20: case 21: case 22:
        printf("Добрый вечер!\n");
        break;
    default:
        printf("Ошибка! Введите число от 0 до 23.\n");
        break;
    }
    return 0;
}
```
